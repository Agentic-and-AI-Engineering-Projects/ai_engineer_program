# 18 — Refusal-as-Tool

**Status:** placeholder · queued.

## What this pattern is

Explicit refusal as a typed return shape.

Instead of natural-language 'I cannot help with that', define a refusal as a structured tool call: refuse({reason, category}). Makes refusals machine-readable, auditable, and easy to log.
