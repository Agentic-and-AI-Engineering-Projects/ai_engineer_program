## What this pattern is

Risky decisions pause for human + audit trail.

LangGraph interrupt + checkpoint, or external task queue. Agent pauses on a decision matching a risk rule, surfaces context to a human, resumes after approval. Audit trail captures the human decision for post-hoc analysis.
